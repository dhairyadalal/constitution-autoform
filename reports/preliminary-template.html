Four documents, five diagnostic cases, four target backends, two prompt modes, and two repetitions. The same pinned Codex model generated and reviewed every candidate.

The main limitation in this run is the fidelity of the generated rule sets. Each native checker evaluates the rules supplied to it, so an omitted provision cannot be recovered by a valid proof.     Scope and interpretation

    What these results support

    Formal guarantee

    The checkers establish bounded conflict properties of the generated finite rule sets. They do not prove that every natural-language provision was encoded, that a pending duty will eventually be performed, or that all ambiguity has been resolved.

    Method comparison

    All target conditions share one intermediate rule language. The model saw method-specific guidance, and each native backend checked the resulting rules. Counts by target therefore combine extraction and verification. Eight inconsistent candidates per method are too few for a ranking claim.

    Text interpretation

    The hidden authoring core supplies a designed target, while three same-model Codex calls assess source defensibility. Exact structural mismatch can include defensible rewordings. Agent agreement can reflect shared model errors. The review evidence supports error analysis, not a human-annotated semantic gold standard.
