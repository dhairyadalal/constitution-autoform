Do formal checks preserve
constitutional requirements?

A controlled study of autoformalization, bounded coherence, and semantic fidelity

Meridian synthetic constitution benchmark · Frozen run 3f10fb9

Abstract

Autoformalization can make an inconsistent constitution appear coherent when it omits the requirement that creates the conflict. We examine this failure mode with two synthetic constitutions. For each, a consistent document is paired with a version that requires a redacted oversight alert under specified conditions and forbids the same alert before user confirmation. We generate formal rules from each document and check them against a hidden design model and shared diagnostic scenarios. Among 31 valid encodings of the inconsistent documents, 15 lose the designed alert conflict even though their formal checks complete (Figure 2). In one case, Isabelle verifies the absence of a conflict because the encoding omits the alert prohibition. A successful proof therefore needs accompanying evidence that the checked rules preserve the source requirements on which the claimed property depends.

This report presents a completed preliminary run on synthetic documents. All source review was agent-driven; deployed model behavior was not evaluated.

1 Introduction

This paper reports a preliminary investigation of whether natural-language AI constitutions can be translated into formal rules without losing requirements. Public constitutions and model specifications express behavioral constraints, permissions, and priorities in prose [1][2]. Autoformalization research has developed methods for translating natural language into checkable representations across other domains [3]. The preservation of interacting requirements in AI constitutions remains a more specific empirical question. A rule set can be valid and checkable even after translation changes which actions it requires or forbids.

The goal of this research effort is to make constitutional requirements checkable while preserving their intended meaning. This requires methods that identify obligations, prohibitions, permissions, conditions, and priorities in the source text; verify properties of the resulting formal rules under stated assumptions; and test whether the rules still reflect the text. The present study establishes a controlled baseline for those tasks. It uses synthetic documents whose intended rule relationships are recorded before generation, then examines where generated encodings retain or alter them.

Behavioral audits address a related question at a later point in the process. Jakkli et al. decompose public specifications into testable tenets, generate adversarial scenarios, and validate flagged model behavior against the text [4]. Here the object of evaluation is the constitution’s generated representation. The same diagnostic scenarios are applied to each encoding so that differences in computed action status can be traced to the provisions that were preserved, changed, or omitted.

Our controlled test places a known conflict in a fictional assistant’s operating rules. Meridian must send a redacted alert when a serious incident is verified and its authorized oversight channel is available. In the inconsistent version, another clause forbids any alert until the user confirms it. A diagnostic scenario supplies a verified incident and an available, authorized channel, but no user confirmation. Both clauses then apply to the same action, with no stated priority to resolve them. The paired consistent version tests whether an encoding introduces a conflict that the document does not contain.

We evaluate four claims separately: whether an encoding is valid, whether its rules contain a bounded conflict, whether it preserves the designed relationships, and whether its interpretation is defensible against the natural-language text. The distinction matters because a native checker evaluates the submitted rules. As the results show, some encodings pass that check after losing the planted conflict. This preliminary finding identifies the translation problem that subsequent constitution design and compliance experiments must address.

2 Methods

2.1 Documents, environment, and diagnostic cases

The benchmark controls the underlying rule structure while varying document style and consistency. Its two original synthetic families are a contextual, character-oriented constitution and an operating specification organized around authority and scope. Their styles draw on Anthropic’s constitution and OpenAI’s Model Spec [1][2]. Each document contains 11 clauses and 840–964 whitespace-delimited words. The shared fictional assistant, Meridian, summarizes incident records, sends oversight alerts, and handles export requests. Using the same environment and designed core makes the resulting encodings directly comparable.

A hidden authoring model specifies the intended relationships in the checkable core. It contains nine base rules and one additional prohibition for each inconsistent version. The mutation prohibits a redacted alert before user confirmation, while the existing duty requires that alert when a severe incident is verified and an authorized channel is available. The core contains no override resolving this pair. The hidden model supplies a controlled target for fidelity analysis; its nine or ten rules do not exhaust every value or procedural instruction in the prose.

Five shared scenarios reveal how each encoding treats actions under uncertainty, export confirmation, redaction, unavailable oversight, and the alert conflict. The decisive alert scenario sets the incident to verified, the channel to authorized and available, and user confirmation to false. Across the scenarios, we query 15 action statuses per valid encoding, including an audit action after an external alert. The formalizer sees neither the scenarios nor the hidden design model. Evaluators then supply the scenario facts directly to the checker; the study does not test extraction of facts from scenario prose.

2.2 Representation and bounded conflict checking

Every candidate uses a common rule schema that makes force, scope, timing, and priority explicit. A rule records an obligation, prohibition, or permission; one of nine actions; positive and negative guards over 14 Boolean facts; a current- or next-decision due phase; explicit override targets; and a source clause with a quoted span. This shared representation supports deterministic compilation to each native backend. It also restricts what the study can say about the expressive advantages of the target languages.

r = ⟨force, action, G+, G−, due, overrides, source⟩

Bounded coherence requires the absence of a simultaneously effective obligation and prohibition on the same action. The checker searches for a Boolean state satisfying the environment invariant, action preconditions, and the guards of an unresolved pair. Explicit overrides can suppress a rule; permission alone does not cancel a prohibition. Here, a “reachable” witness means a state satisfying these constraints. The global conflict query ignores due-phase labels; those labels affect the diagnostic distinction between required and pending. The check does not establish reachability through a complete transition system or eventual fulfillment of a deferred duty.

Conflict(R) ⇔ ∃s, a : W(s) ∧ Pre(a,s) ∧ OR(a,s) ∧ FR(a,s)

W encodes the world invariant; Pre encodes action preconditions; OR and FR are effective obligations and prohibitions after explicit overrides. The global conflict query does not distinguish due phases.

Native checks establish the conflict property of the submitted rule set. The SMT backend uses Boolean constraints in Z3; the FOL backend uses predicates over states and actions in Z3; the ASP backend uses clingo; and Isabelle builds a generated theory stating either absence of a bounded conflict or existence of a witness. A separate finite analysis provides the common assessment. Agreement between these implementations supports the execution of the checking pipeline, but shared assumptions and compilation still constrain the guarantee.

2.3 Generation conditions and evaluation measures

Each of the four documents is formalized under four checker targets, with two prompt variants and two repetitions per condition. This produces 64 candidate rule sets. Direct prompting requests rules immediately; structured prompting first requests a decomposition of provisions and their relationships. The same model, gpt-6-luna at medium reasoning effort, receives the full document, environment, and public vocabulary in every condition. Its prompt also specifies the target checker. The target comparisons therefore reflect both target-specific guidance during generation and the subsequent native check.

Exact fidelity matches force, action, positive and negative guards, due phase, and override targets. Matching consumes each generated rule at most once; unmatched design rules and unmatched generated rules are reported separately. Complete exact fidelity requires neither kind of mismatch. This measure detects changes that merit inspection, but it can penalize an equivalent encoding, a rule split across clauses, or a defensible addition outside the core. Case diagnosis therefore complements structural matching by measuring the consequences on shared inputs.

Agent review evaluates source defensibility without human annotation. Three separate calls to the same pinned model inspect each valid candidate and the source text, classify each rule as supported, unsupported, or uncertain, and identify omissions. Six benchmark-review calls preceded the frozen run. The candidate review adds 189 calls to 64 generation calls, for 253 calls in the main run. Separate calls supply multiple readings, but they do not eliminate correlated errors from a shared model.

The experiment preserves an audit trail for each condition. The frozen inputs are hash-checked; prompts, model metadata, generated rules, native theories, checker outputs, and reviews are saved. The main run reports 2,029,938 CLI tokens and approximately 20 minutes 43 seconds elapsed with four workers. Generation prompts exclude hidden inputs, although local CLI filesystem access is not a hard isolation boundary. These records support inspection of this run; two repetitions per condition do not establish stability across models or document distributions.

3 Results

Which target performed best in this run?

SMT-targeted generation recovered the planted alert conflict most often: 6 of 7 valid encodings of the inconsistent documents, compared with 4 of 8 for FOL or ASP and 2 of 8 for Isabelle. ASP had slightly higher agreement across all diagnostic case statuses. No target produced a fully faithful exact match to the designed core.

3.1 Validity does not ensure conflict preservation

The formal checks complete for almost every generated encoding, but many miss the alert conflict planted in the inconsistent documents. Of 64 candidate rule sets, 63 pass representation validation and complete a native check; one contains an invalid override reference. The check finds no conflict in any of the 32 encodings of the consistent documents. It finds the alert conflict in 16 of 31 valid encodings of the inconsistent documents, while 15 appear coherent. Every detected conflict includes the intended pair of source clauses; three encodings also produce an additional pair. The difference between completed checks and recovered conflicts identifies translation as the failure point in this benchmark.

Native outputs agree with the finite conflict analysis wherever parity is recorded. All 47 SMT, FOL, and ASP outputs agree with that analysis, and all 16 Isabelle theories build successfully. This rules out a failed native invocation as the explanation for the missed conflicts in these candidates. It does not establish the correctness of the shared semantics or compiler. In particular, a successful Isabelle build can certify the absence of conflict in a rule set that has lost a source requirement, as the example in §3.3 demonstrates.

3.2 Formalization quality across target conditions

SMT-targeted generation recovers the planted alert conflict most often. It retains the conflict in 6 of 7 valid encodings of inconsistent documents, compared with 4 of 8 for FOL, 4 of 8 for ASP, and 2 of 8 for Isabelle. Its recoveries occur in both document styles: 3 of 4 character-oriented encodings and all 3 valid authority-oriented encodings. The authority-oriented set also contains the study’s one invalid candidate. This gives SMT the strongest observed result on the experiment’s primary test of whether a consequential relationship survives translation.

Broader quality measures do not produce the same ordering. ASP has the most exact matches to individual designed rules (97 of 152) and the most case-status agreements (200 of 240); SMT is close on these measures (90 of 142 and 186 of 225). Neither target condition yields a candidate that exactly reproduces the full designed core. Isabelle has the most candidates with exact source quotations (14 of 16), yet recovers the alert conflict in only 2 of 8 inconsistent encodings. Literal quotation therefore provides traceability without establishing faithful interpretation. Table 4 presents the denominators and reviewer judgments for all four targets.

The consistency controls show no spurious conflicts, while the inconsistent texts often lose their intended one. The conflict is retained in 9 of 16 valid encodings of the character-oriented document and 7 of 15 of the authority-oriented document. None of the 32 consistent encodings produces a conflict. These controls establish that the checker did not invent conflicts on those inputs; they cannot establish that the consistent documents were translated completely, because omitted duties may also leave an encoding conflict free.

3.3 What the missed conflicts look like

The unconfirmed oversight-alert scenario shows how a missed conflict changes the computed action status. Its verified incident, authorized and available channel, and absent user confirmation activate both sides of the designed conflict. Among the 31 valid encodings of inconsistent documents, 16 classify the redacted alert as conflicting, 10 as required, 4 as pending, and 1 as unknown. The latter three outcomes arise from rule sets that no longer express the intended simultaneous obligation and prohibition. The traces below identify the changes behind selected outcomes.

Preserved conflict: the obligation and prohibition survive together

One SMT-targeted encoding preserves both sides of the alert conflict. Rule C4a requires a redacted alert for a verified severe incident with an authorized, available channel; rule C5a forbids it without user confirmation. Both apply in the unconfirmed alert scenario, and neither overrides the other. Z3 finds a conflict witness, and the diagnostic status is conflicting. This encoding still lacks exact matches to two other rules in the hidden design model, so the recovered conflict does not establish complete fidelity.

3.4 Structural fidelity and agent judgment remain unresolved

No valid candidate exactly matches the complete designed core. Every valid candidate lacks at least one exact design-rule match, and 62 of 63 also contain unmatched generated rules. Exact source quotations occur throughout 47 of 63 candidates. The concrete omission and timing examples establish consequential translation errors, but the aggregate structural counts cannot distinguish all errors from equivalent or defensible encodings. They support a requirement for further semantic adjudication rather than a conclusion that every unmatched rule is wrong.

Agent review provides limited agreement about the generated rules. Of 512 rules, 137 receive unanimous support, 12 unanimous rejection, and 102 unanimous uncertainty; the remaining 261 have mixed judgments. All 189 review calls complete. This distribution indicates that many interpretations remain unsettled under the chosen review procedure. Same-model voting cannot resolve whether agreement reflects correctness or a shared bias, so the votes serve as evidence for inspection rather than a calibrated semantic score.

Case-status agreement supplies a useful diagnostic without establishing end-to-end compliance. The generated and designed encodings agree on 720 of 945 action-status queries. These queries repeat the same 15 probes across candidates, so they are not independent behavioral trials. They also test only the supplied cases and facts. Their contribution is to make representational differences concrete, as when a designed conflict becomes a requirement to notify oversight without a recorded conflict.

4 Discussion

4.1 Conditional guarantees require an account of preservation

The study identifies semantic preservation as an unresolved dependency of constitutional verification. A coherence result quantifies over the encoded rules and their modeled conditions. In the Isabelle omission example, deleting a source prohibition produces a rule set for which the coherence theorem succeeds. The result therefore supports attaching a preservation argument to any claimed constitutional guarantee: which provisions were represented, which relationships were retained, and which interpretations remain open. A native proof alone cannot supply that argument.

Coherence and fidelity need to be assessed jointly when constitutional revisions are evaluated. Removing either member of an obligation–prohibition pair can eliminate its conflict without preserving the original requirements. The current run observes this effect during extraction, before any repair objective is introduced. It motivates a falsifiable next experiment: compare conflict-only revision with revision constrained to preserve protected provisions and evaluate both on withheld counterexamples. Such an experiment would test whether symbolic feedback improves constitutional design or rewards weakened representations.

4.2 Which representation should be used next?

For a follow-up study using this finite rule vocabulary, the strongest provisional choice is the shared rule schema with SMT/Z3 as the primary checker. SMT-targeted generation recovers the planted conflict in 6 of 7 valid attempts across both document styles, and its case-status agreement is close to ASP’s. This recommendation is about the complete pipeline tested here: the model first writes the common rule schema, receives target-specific guidance, and the compiler produces a native theory. It does not establish that SMT is intrinsically better at representing constitutions.

ASP is the most useful comparison condition for the next study. It has the highest exact designed-rule count and case-status agreement, although the latter exceeds SMT by less than one percentage point after accounting for the different denominators. Its conflict recovery is lower, at 4 of 8 valid inconsistent encodings. FOL offers no clear advantage on these measures. Isabelle successfully checks all 16 submitted theories and has the most exact source quotations, but recovers only 2 of 8 planted conflicts. The Isabelle failure trace shows why a stronger proof procedure cannot compensate for a missing source provision.

No target condition is ready to certify a natural-language constitution on the strength of a successful backend check alone. Every valid encoding misses at least one exact designed rule, and same-model review cannot settle all interpretive disputes. In the next experiment, the SMT baseline should be paired with an explicit preservation assessment of obligations, prohibitions, conditions, and priorities, plus diagnostic cases that test the consequences of disputed translations. Running another checker on the same incomplete rule set would repeat the same semantic omission.

4.3 Scope of the recommendation

The recommendation applies to conflict recovery in this two-family, finite Boolean benchmark. The model receives different guidance for each target, while every native backend checks rules compiled from the same intermediate representation. The experiment therefore compares target-conditioned pipelines, not independently generated SMT, FOL, ASP, and Isabelle specifications. A controlled follow-up should check fixed extracted rules across backends and separately compare independently generated native representations before claiming that one formal language is more effective.

4.4 Limits and discriminating follow-up experiments

The benchmark’s narrow scope limits generalization across constitutional requirements. Four documents instantiate two styles and one shared mutation schema in a finite world of 14 facts and nine actions. The study does not cover richer authority relations, unrestricted quantification, competing obligations across actions, or temporal liveness. Expanding to independently authored conflict types and held-out document families would test whether the observed preservation failures persist beyond this particular oversight example.

Evaluation uncertainty limits claims about overall semantic fidelity. Exact signatures are stricter than semantic equivalence, and three calls to one model can share an interpretive error. All reviewer calls report some omission, including prose outside the designed core. A stronger agent-only evaluation could combine model diversity, explicit alternative readings, and counterexample searches for semantic equivalence. Its success criterion should be adjudication of consequential disagreements, not merely a higher agreement rate.

4.5 Conclusion

This preliminary run demonstrates that a constitutional encoding can pass a native formal check after losing the provision responsible for a designed conflict. Fifteen of 31 valid encodings of inconsistent documents fail to retain that conflict, and the Isabelle example identifies a specific missing prohibition. These results make source preservation an explicit requirement for interpreting a formal guarantee about a constitution. The next experiments should test whether that requirement can be maintained across new document types and through automated revision.
