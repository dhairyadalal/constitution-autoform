# Repository instructions

This is SPAR research, separate from MATS operations. Preserve the common synthetic benchmark across methods. Record assumptions and unsupported cases instead of inventing unique meaning. Do not use reference votes or held-out labels when generating a formalization. Never edit a frozen benchmark in place after a run; create a new version. Save prompts, candidate source, model metadata, and errors for every run. Do not describe agent-generated reference judgments as human annotation or semantic ground truth.
